My project is a 6-DOF robotic-arm kinematics engine.

It will:
1. Represent a robot using DH parameters.
2. Calculate forward kinematics.
3. Calculate a Jacobian.
4. Solve inverse kinematics numerically.
5. Display the robot and its workspace.
A coordinate frame is like a small invisible ruler attached to a robot part.
It describes the part's position and orientation.
